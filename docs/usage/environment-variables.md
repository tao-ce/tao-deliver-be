# Environment variables

`tao-deliver-be` is using [Symfony Dotenv](https://symfony.com/doc/current/components/dotenv.html) component which helps
to work with environment variables regardless of the system.

If the required environment variable doesn't exist in the given system, the application will try to find it in the given
`.env` files.

## Files

- `.env` - get loaded for all environments
- `.env.dev` - get loaded only for `dev` environment
- `.env.prod` - get loaded only for `prod` environment
- `.env.test` - get loaded only for `test` environment
- `.env.local` - it can be used to override the default values
